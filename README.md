# 第一餐饮大楼 · 菜单索引

一个面向手机和电脑的静态网页原型，可按菜名、餐饮品牌、档口、分类、价格状态、口味/形式和供应时段筛选清单。收藏保存在当前浏览器。

## 公开预览

访问 [第一餐饮大楼菜单索引](https://minhang-canteen-index.hushed-cod-2104.chatgpt.site/)，手机和电脑均可打开。菜品图片目前是按形式复用的示意图，页面不会把它们标成真实档口照片。

仓库开启 GitHub Pages 后，`.github/workflows/pages.yml` 会在 `main` 有更新时自动发布 `dist/`。仓库的 Pages 来源选择 **GitHub Actions**；个人公开仓库名为 `campus-canteen-menu` 时，网址为 `https://perfecth154.github.io/campus-canteen-menu/`。

## 本地运行

在项目根目录运行：

```bash
python3 -m http.server 8000 --directory dist
```

然后访问 `http://localhost:8000`。纯静态页面不需要数据库、账号系统或应用服务器。

## 更新 Excel 清单

准备包含原有 Excel 工作表的文件夹，文件名保留“中式点心”“民族风味”“淮扬快餐”“自选教工”“超霖美食”中的对应关键词。安装一次解析依赖后导入：

```bash
python3 -m pip install -r requirements.txt
python3 scripts/import_menu.py /path/to/excel-folder
```

默认会更新 `dist/data/menu.json`。脚本按 A 列序号、D 列菜名、E 列价格、F 列备注读取记录，并向下补齐合并单元格中的餐饮楼和档口名称。导入时会按明确的菜名词项生成酸、甜、苦、辣、麻等候选口味，以及米饭、面食/粉、汤羹、粥、点心、热菜等形式标签。没有明确口味词的菜保留“口味待判”，不强行猜测。导入日期只表示这次转换的时间，不代表原表发布日期。

供应时段只从原表工作表名称初标：`淮扬-早餐`归为早餐，`淮扬-午餐、晚餐`同时归为午餐和晚餐；其他记录的时段保留待确认。这表示清单归类，不代表档口实际营业时间。

人工校正写入 `scripts/manual_tag_overrides.json`，以菜品 `id` 为键，字段使用 `tasteTags`、`formTags` 和 `mealTags` 数组；下次导入时会优先采用人工标签。这些人工校正可积累成后续分类器的训练样本，规则初标不等于模型判断。

## 当前数据边界

- 764 条菜品记录，来自 5 个工作簿和 24 个工作表。
- 357 条有数字价格，其中 10 条原表价格为 0；原表没有说明 0 的含义，页面标为待核实，不当作免费。
- 399 条价格为空，8 条价格栏是文字标记；文字标记按原文显示。
- 口味从菜名和分类中提取明确线索；缺少线索时显示“口味待判”。用户可在同一组里多选，口味、形式、供应时段跨组同时生效。
- 218 条有工作表时段标注（58 条早餐、160 条午餐及晚餐），其余 546 条标为“时段待确认”；这些标签不等同于档口营业时间。图片为 4 张本地示意图，按米饭、面点、汤羹等形式复用。
- 清单没有菜品照片、每日更新时间、营业时间、实时库存或营养信息。页面不声称这些信息实时有效。
- 收藏仅存在当前浏览器设备；评价、评论和跨设备同步需要登录、数据库与内容审核，不包含在此原型内。
